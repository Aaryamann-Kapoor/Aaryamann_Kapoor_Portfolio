Business Entity Resolution (AMLC)

An automated entity resolution framework for matching and deduplicating corporate entities across multi-source financial datasets to improve Anti-Money Laundering Compliance (AMLC).

Problem

Financial institutions receive business registry data from multiple global providers. Due to typos, abbreviation variations, address changes, and transliterated business names, identical commercial entities appear as distinct records. This fragmentation hampers anti-money laundering (AML) tracking and compliance auditing.

Approach

Engineered a multi-stage entity resolution pipeline. The system performs blocking to minimize pairwise comparison space, applies string distance metrics (Jaro-Winkler, Levenshtein, Cosine TF-IDF) and phonetic encoding, and uses supervised classification models to score pair similarity and cluster true entity matches.

Tech Stack

  • Language: Python 3
  • Data Processing: Pandas, NumPy, Regex
  • Record Linkage & ML: Scikit-learn, RecordLinkage toolkit, RapidFuzz / String distance algorithms
  • Storage & Queries: SQL / DataFrames

My Role

Designed and built the Python pipeline, implemented record linkage blocking techniques to optimize speed across large datasets, and evaluated classification models for optimal precision/recall trade-offs.

Outcome

Achieved high deduplication accuracy while significantly reducing computational comparisons through smart blocking, enabling reliable entity matching for compliance auditing workflows.
