Urja Vridhi (Watt-Wise 2.0)

An open-source energy intelligence platform for campuses, combining live ESP8266 hardware telemetry with an LSTM + XGBoost forecasting engine, end-to-end encrypted datasets, and anomaly tracking.

Problem

Educational institutions and large campus facilities often face high operational costs and undetected energy wastage due to unmonitored power consumption across departments. Legacy meters lack real-time granularity, and facility teams lack predictive tools to anticipate peak load spikes or detect equipment anomalies before outages occur.

Approach

Urja Vridhi pairs physical ESP8266 IoT sensors with a dual-layer forecasting pipeline. Sequential time-series patterns are captured via Long Short-Term Memory (LSTM) networks, while tabular load factors and temporal features are evaluated using XGBoost. Data telemetry streams securely over encrypted endpoints to a centralized dashboard where administrators receive automated anomaly alerts and peak consumption forecasts.

Tech Stack

  • Backend & API: Node.js, Express framework
  • Machine Learning: LSTM Neural Networks, XGBoostRegressor, Scikit-learn, Python ML pipeline
  • Hardware Telemetry: ESP8266 Microcontrollers, Wi-Fi telemetry protocols
  • Frontend & Security: Dashboard UI, End-to-end dataset encryption, Anomaly detection algorithms

My Role & Context

Built as a collaborative team project alongside Samridhi Parashar and Saksham Parashar. The project originally debuted as Watt-Wise 1.0 at FossHack 2026. Following initial hackathon feedback, we expanded it into Urja Vridhi (Watt-Wise 2.0) — architecturalizing end-to-end encrypted telemetry ingestion and refining the hybrid ML forecasting model.

Outcome

Successfully implemented a functional open-source platform capable of continuous live hardware telemetry ingestion and reliable load forecasting, enabling proactive energy management and zero-day anomaly detection for campus infrastructure.
