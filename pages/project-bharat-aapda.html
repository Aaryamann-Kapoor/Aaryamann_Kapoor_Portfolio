Problem

During emergency situations and natural disasters in India (floods, cyclones, earthquakes), communication channels get overloaded and rescue response teams struggle with fragmented information regarding victim locations, shelter capacity, and supply distribution.

Approach

Bharat Aapda Prabandhan aggregates incident reports and spatial telemetry into an accessible crisis management interface. By structuring emergency requests and applying basic prioritization heuristics, the system helps match urgent distress signals with nearest available relief supplies and response teams.

Tech Stack

  • Core Backend: Python / Web Framework
  • Data Processing: Pandas, NumPy, Spatial Data Processing
  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Version Control: Git & GitHub

My Role

Lead developer responsible for architecture design, data structuring for incident reporting, and implementing the front-end user experience tailored for high accessibility under stressful usage conditions.

Outcome

Designed and built a functional prototype demonstrating fast incident tracking and centralized disaster response workflow, showcasing how technology can improve disaster readiness in regional settings.
